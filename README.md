# Projet Tine-data-scientist (Analyse Médicale)

## Краткое описание проекта (Description)
Ce projet est un pipeline de Machine Learning pour l'analyse de données médicales (prédiction de risque de maladie). Il inclut la préparation des données, l'entraînement du modèle et l'interprétation des résultats. Pour chaque lancement, les résultats sont sauvegardés dans le répertoire `results/experiments/`.

## Требования к окружению (Prérequis)
* Python `>=3.10,<3.11`.
* `uv` pour créer et gérer l'environnement.
